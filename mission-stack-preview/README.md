# Mission Stack — preview directory

Three redesign directions for the Mission Stack rebrand, built for review before anything goes live. See `../DESIGN.md` and `../design-rationale.md` for the full brief.

- `v1-editorial-warm/` — Stripe/Basecamp-leaning: serif headlines, warm parchment background, calmest of the three.
- `v2-systems-dark/` — Linear-leaning: charcoal/navy dominant, monospace accents, grid motif, most "technical/systems" feeling.
- `v3-modern-approachable/` — lighter Basecamp lean: brightest, roundest, friendliest, closest to a SaaS product feel.

Each is a self-contained static HTML file (open directly in a browser, no build step). `sitemap.xml`, `robots.txt`, and `llms.txt` in this directory are drafts for `missionstack.us` and are **not** wired to any live domain.

This directory does not affect production. The live site (`index.html`, `en/index.html`, `sitemap.xml`, `robots.txt` at the repo root) is untouched.
